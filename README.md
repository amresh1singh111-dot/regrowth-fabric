# Regrowth (Fabric, Minecraft 26.3)

Creatures eat and regrow plants. Villagers improve their villages.

Fabric port of Mactso's Regrowth, based on the 1.21.6 Forge source. MIT licensed.

Build: JDK 25, then `./gradlew build`. The jar is in `build/libs/`.
Config file (created on first run): `config/regrowth.properties`.
